# WorkflowMoves: capability reference

WorkflowMoves packages guarded route manifests, additive text insertion/copy behavior, versioned rules, task guides, portable skills, validation tests and immutable release archives with checksums. Check the latest release before every workflow and preview a route with `install.py --check` before applying it.

An installed block proves configuration, not that a workflow used every capability or produced a reviewed result. Preserve project-owned text, version ownership, gates and exact route receipts.
