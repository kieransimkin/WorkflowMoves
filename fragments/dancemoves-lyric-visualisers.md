### Inline scrolling lyric visualisers

For a masked scrolling track on a live EPK, follow
`Workflows/dancemoves-lyric-visualisers.md`. Derive release-scoped CSS from the
campaign's existing visual-language assessment. Use the selected LRC and
canonical master with the DanceMoves 3.5.0+ inline host. Retain the readable
transcript and check actual song playback at desktop and mobile widths before
requesting the exact publication approval.
