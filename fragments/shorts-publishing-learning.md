## Platform-specific opening decisions and report updates

Use [Shorts performance learning](Workflows/shorts-performance-learning.md)
for YouTube, TikTok, Instagram, Facebook, X and LinkedIn. Choose one primary
native opening measure, a watch/meaning guardrail and downstream response or
listening diagnostic. Compare actual publication ages and compatible source
windows; no single platform's reach winner controls another platform.

Register a concrete control and treatment before publication. Preserve the
exact soundtrack/duration and later edit for a visual-opening pair; document
confounders for an audio/excerpt test. Verify native IDs, real live times,
source/copy/cover hashes and exposure before marking a test active. Reconcile
the existing queue first. Review at24h/72h/seven days on the next eligible
existing analysis run; those ages create no additional job or posting duty.

Write qualified results and decisions to the private living report and release
ledger. Keep no distribution, unavailable, tiny sample and unjoined test files
inconclusive. Dated account hypotheses retained below are historical evidence;
the latest qualified report and current campaign test govern the next decision.
