# FrameRudiments: complete capability reference

Inspected stable source: [v0.4.1](https://github.com/kieransimkin/FrameRudiments/releases/tag/v0.4.1), commit `8ddbf6ea80ea447f467019f176610a763770a87a6`. This is a dated baseline; [check current releases before every new workflow](../workflows/release-preflight.md).

## Choose and use a route

| Goal | Supported route and evidence |
|---|---|
| Plan and render | Use the full compositor workflow: exact source/excerpt/phase clocks, hashes, frame ledger, preflight, encoded render and separate visual/listening review. |
| Compose the full feature set | Choose native or saved movement, every renderer family, sprites/atlases, rich line/word lyrics, particles, 3D meshes, style modulation, stem drivers, mattes, keyframes, displacement and post effects. |
| Route feedback and clean overlays | Select per-element feeds and windows, intermediate stage injections and final overlays. Replay sequential Butterchurn/projectM history; pin runtime, preset and source identities. |
| Author and profile | Use the released shared-timeline authoring UI for export-only drafts; use temporal-first PixelCue/PrismMoves preset profiling, bounded semantic budgets and saved-report replay. Source helper scripts ship separately from the wheel. |
| Render native rangoli petals | Use the `rangoli` renderer or `demo --rangoli`: independent scale, rotation and lift axes, explicit halo/stroke bounds, transparent fills and optional glow. Compose the texture-free projectM background through existing routing so petals and lyrics remain clean overlays. |
| Measure controlled audio response | Use `Run-ControlledPresetAnalysis.ps1` or `controlled_preset_analysis.py` for tone/noise/silence probes, deterministic sample clocks and evidence-linked response comparisons. A synthetic response profile is renderer evidence, not music analysis or a listener judgement. |

Read [the full compositor workflow](../workflows/framerudiments-complete.md) for the feature/configuration/verification map, authoring and exact CLI sequence.
