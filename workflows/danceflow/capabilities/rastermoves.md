# RasterMoves: complete capability reference

Inspected stable source: [v0.3.4](https://github.com/kieransimkin/RasterMoves/releases/tag/v0.3.4), commit `db26fbf1211f04da5f2d4f6e0eb78387597f6149`. This is a dated baseline; [check current releases before every new workflow](../workflows/release-preflight.md).

## Choose and use a route

| Goal | Supported route and evidence |
|---|---|
| Choose processing | Inspect plugin/model catalogue, dry-run discovery, comparison/resume, CLI/GUI and Python routes. Keep originals and an unrefined baseline. |
| Control execution | Use target sizing, alpha/crop preservation, tiles/overlap, memory, precision/device options and bounded batch comparison. Install only authorised useful models into project-local models/. |
| Review refinement | Diffusion refinement and protection masks synthesise detail; verify lettering, edges, alpha and identity. Retain hashes, provenance, seeds and timing/resource traces. |
