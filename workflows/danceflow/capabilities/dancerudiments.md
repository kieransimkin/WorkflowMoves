# DanceRudiments: complete capability reference

Inspected stable source: [v0.3.0](https://github.com/kieransimkin/DanceRudiments/releases/tag/v0.3.0), commit `b89d1b80fcd8a8d8e02394ec718b6f4debd97b94`. This is a dated baseline; [check current releases before every new workflow](../workflows/release-preflight.md).

## Choose and use a route

| Goal | Supported route and evidence |
|---|---|
| Select a native pattern | Inspect descriptors and the complete default/club/dancefloor catalogue; preserve integer 64-pip samples and each procedural period. |
| Author a missing movement | Use curve, LFO, sampled and seeded-random sources plus rational-beat event/gesture authoring and bounded custom libraries; do not copy a motion engine. |
| Play captured dimensions | Use native N-dimensional recording playback and actual comparison harness; captured data stops at its bounds, while procedural patterns may wrap. |
| Integrate a binding | Use released C++, Python, WASM/TypeScript or C# packages; verify the actual native module and matching package before relying on a viewer or authoring API. |
